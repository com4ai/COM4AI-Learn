# Generative AI

Generative AI creates new content from patterns learned during training. Depending on the model and input, that content can include text, code, images, audio, video, or other structured outputs.

```text
Instruction or input → generative model → newly generated output
```

- [Large Language Models](Large-Language-Models/README.md) — text- and code-generating models, prompting, chatbots, retrieval-augmented generation, and practical LLM applications.
