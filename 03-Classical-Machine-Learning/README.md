# Classical Machine Learning

Classical machine learning uses algorithms that learn patterns from structured data. It is often the right choice when data is tabular, the dataset is moderate in size, the result must be easy to explain, or a lightweight model is needed.

```text
Data → feature preparation → machine-learning algorithm → prediction or decision
```

This section will cover supervised learning, unsupervised learning, regression, classification, clustering, decision trees, random forests, support vector machines, k-nearest neighbors, and model evaluation.

Classical machine learning complements neural networks: it is not an older approach to discard, but a practical family of methods that remains widely used in real AI systems.
